# CodePocket

"A small app to save and organize code snippets I reuse, so I don't have to dig through old projects."

## Why I built it

"I wanted a project to practice React hooks or TypeScript and more."

## Features

- Add, edit, and delete snippets
- Search by title, description, or tags
- Filter by tag and mark favorites
- Syntax highlighting with multiple code themes
- Light/dark mode
- Saves everything in the browser (localStorage)
- Export/import snippets as JSON

## Tech stack

React, TypeScript, Vite, highlight.js

## Run it locally

    git clone https://github.com/withsarath/CodePocket
    cd CodePocket
    pnpm install
    pnpm dev
